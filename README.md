Привет!
В данном проекте реализована онлайн-библиотека, где пользователи могут добавлять свои книги и просматривать чужие. Ulibrary содержит следующий функционал:
- Регистрация новых пользователей
- Аутентификация зарегистрированных пользователей
- Просмотр названия, автора, описания и создателя всех добавленных в систему книг (для всех)
- Добавление новых книг, удаление и редактирование информации старых кник (для аутентифицированных пользователей)

Данный проект посвящён изучению python-фреймворка FastAPI, хотя гитхаб решил, что код на js преобладает \_('-')_/

Hi!
This project implements an online library where users can add their own books and view others' books. The ULibrary contains the following functionality:
- Registration of new users
- Authentication of registered users
- View the title, author, description and creator of all books added to the system (for everyone)
- Adding new books, deleting and editing information about old books (for authenticated users)

This project is dedicated to learning the FastAPI python framework, although github decided that the js code prevails \_('-')_/
